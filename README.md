# Escape Campervans booking flow prototype

Clickable redesign prototype of the booking flow (Van, Extras, Details & payment),
with a built-in walkthrough comparing each change against the current live site.

**Live: https://osipapa.github.io/escape-booking-prototype/**

## Run locally
Open `index.html` in any browser. No build step, no dependencies.

## Contents
- `index.html` - the prototype (single file, all CSS/JS inline)
- `assets/` - "before" screenshots of the live site used by the walkthrough

## Deployment
Served by GitHub Pages from `main` / root. Any push to `main` republishes the site.
